APENAS ADMINISTRADOR

Transferências para o computador

Pelo celular, selecione os arquivos, navegue nos discos do computador (por exemplo, K: → Pasta X → Pasta Y) e escolha onde deseja salvar. Nada é sobrescrito. Visitantes apenas baixam itens públicos da biblioteca.

Selecione arquivos e escolha uma pasta de destino no computador.

Limite: 2 GB por arquivo. O serviço deve ter permissão de gravação no destino; pastas do Windows, aplicativos, links simbólicos e a raiz de cada disco são bloqueados. Novos arquivos serão reconhecidos após atualizar a biblioteca, se o destino estiver catalogado.

LIMPEZA INTELIGENTE

Encontrar arquivos duplicados

Compare seus arquivos sem excluir ou alterar nada. Arquivos idênticos são confirmados por SHA-256; nomes semelhantes são apenas sugestões para revisão. A área protegida não é analisada.

Ainda não analisado.

Confira as cópias antes de selecionar uma para a Lixeira. Dois arquivos com o mesmo nome podem conter dados diferentes. A estimativa de espaço economizado não considera arquivos vinculados, compressão ou deduplicação do disco.

O sistema faz uma cópia diária do SQLite e configurações, conservando até sete backups em Dados\Backups. Arquivos originais não entram no backup.
